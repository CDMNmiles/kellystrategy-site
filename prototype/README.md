# 凱利策略互動原型 V1

日期：2026年11月8日｜美国洛杉矶时间

## 打開原型

[凱利策略網站預覽](https://kellystrategy-preview.wenmai.chatgpt.site/)。目前為僅供擁有者檢視的版本，使用相同ChatGPT帳號登入；原站 `kellystrategy.org` 尚未替換。

## 已實現

- 四大分類、子欄目篩選與可分享的查詢條件。
- 12支已核對的公開影片、原始封面、獨立觀看頁及YouTube跳轉。
- 公開說明已有時間點的影片章節；未取得可靠摘要的條目如實標示。
- 課程中心、3個課程介紹頁、公開郵件入口及微信號複製。
- 百家樂工具中心與2個工具介紹頁，版本待接入。
- 賭場追查專題、原站第003期文字版、關於與搜尋。
- 手機窄屏導航，基本簡繁關鍵詞搜尋。

生成28個內容頁、404與手機版檢查頁。這是首批原型，並非全頻道資料匯入；正式`content/catalog.json`尚未完成發布資料遷移。影片、課程和工具暫由本目錄資料驅動，後續再接統一發布契約。

## 本地生成

`node prototype/build.mjs`

生成`dist/`，由靜態伺服器提供。HTML已包含主要文字及連結；篩選、搜尋、複製和章節由`client.js`處理。原型設定`noindex`，不與正式站競爭收錄。

## 已檢查

全部生成HTML內鏈目標存在；未將私人Drive來源放入頁面。瀏覽器檢查了分類、篩選、影片頁、課程、微信複製和簡體搜尋。以390px的實際iframe視口檢查手機首頁，導航全部入口可見。
