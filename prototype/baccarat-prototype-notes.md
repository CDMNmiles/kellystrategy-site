# 百家乐单模块原型

本次只替换 /baccarat/ 并添加其八个系列页，其他既有页面保持原样。

- 首屏 1主推＋3重点视频，标题与真实缩略图直接显示。
- 人气精选依据当前已接入影片的公开播放量快照排序，非全频道历史排名。
- 8个真实 YouTube 播放列表；现场、黑盒子、数据洞察首页各先展示8支，课程系列先展示最多4支。
- 本页更多内容展开、系列完整目录和公开影片弹层播放；会员影片标注并前往 YouTube。
- 1,000+ 是创作者提供的全频道总积累，不是本站已导入数量，不是百家乐子模块总数。预览明确说明目录仍在整理。
- 新朋友／老朋友／观点阅读入口；程序牌观点卡片仅依现有公开视频内容整理，无虚构文章。

## 数据
prototype/baccarat-data.json 来自8个公开播放列表页面，记录抓取时间、来源链接、视频ID、原始标题、时长、公开显示播放量与会员状态。96支去重影片，另首屏沿用既有主管手册视频。
公开播放量可能为约数；会员未公开播放量保持空值，不补零。页面为2026年11月8日快照，未自动刷新。

## 正式播放量接入
YouTube Data API videos.list 可按视频ID获取 statistics.viewCount。正式版拟由服务端定期刷新并保留更新时间；API凭证不能直接放入浏览器代码。当前原型无需新凭证，也不宣称已接通同步。
官方参考：https://developers.google.com/youtube/data/reference/rest/v3/videos/list
https://developers.google.com/youtube/data/reference/rest/v3/videos
