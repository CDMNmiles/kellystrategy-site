# 凱利策略網站 PRD V1

日期：2026年11月8日｜美国洛杉矶时间
状态：开发准备规格；页面、导入和发布功能尚待实现。
负责人：Miles；总控负责范围、目录与验收，执行人员按任务分工实施。

## 1. 产品目标

把凱利策略的影片、专题、文字资料、课程与自研软件组织成可浏览、可观看、可查询的内容总站。网站使用自己的分层目录；YouTube 继续提供影片播放、传播、评论及现有观看权限。

网站同时满足三类任务：按兴趣找内容；围绕一个主题连续观看与阅读；了解课程或使用百家樂工具。频道介绍与内容资料应准确、可读取、可追溯，为搜索系统和 AI 提供清楚信息。收录、排名、推荐和销量是观察结果，不是功能交付承诺。

四大内容分类为「百家樂」「老虎機」「賭場追查」「博彩雜談」；「課程中心」「百家樂工具」为独立导航入口。课程保留在相应主题中交叉展示。观点、策略、课程、现场与风险内容均可归档，不能用单一立场代替目录。

## 2. 用户及关键任务

| 用户 | 进入方式 | 想完成的事 | 成功结果 |
| --- | --- | --- | --- |
| 新观众 | 首页、频道链接、品牌搜索 | 了解频道、选感兴趣的领域 | 能说出主要栏目并进入相关内容 |
| 老观众 | 书签、视频说明、搜索 | 找旧片、系列顺序和最新后续 | 找到目标，观看后可继续同一系列 |
| 专题读者 | 搜索引擎直达文章或影片页 | 查某个问题、出处和不同观点 | 可读到摘要、背景、来源与关联内容 |
| 课程意向观众 | 分类页、课程中心、相关影片 | 看目录、试看和购买条件，再咨询 | 找到同一课程详情，联系信息带课程名 |
| 工具使用者 | 工具入口、百家乐页、相关教程 | 判断软件适不适用并打开或下载 | 看到真实状态、版本和有效入口 |

主要任务从首页到目标详情页不超过三次主要导航点击。搜索输入、播放器操作、阅读展开、发送咨询和软件内部操作不计入导航次数；测试记录必须说明路径。

## 3. 首版范围

### P0：首版必须交付

1. 全站导航、首页、四大分类、系列／专题列表与详情。
2. 已核验发布范围的视频目录、固定观看页、有效 YouTube 跳转。
3. 有实质内容的频道介绍、分类介绍和影片摘要。
4. 课程中心与同一课程权威详情页；通过已核验渠道咨询。
5. 独立百家樂工具中心及工具详情；真实展示可用状态。
6. 公开内容搜索，支持简繁关键词别名与内容类型筛选。
7. 真实资料可用时发布文章、图解、出处和事件后续；可缺全文稿，但不能编造摘要或时间点。
8. 手机适配、键盘操作、错误与受限状态；站点地图、页面标题与可读正文。
9. 可重复的数据导入、发布前校验与维护交接流程。

### P1：首版后按价值增加

经校对的全文稿与逐句跳转、更多历史专题、设备本地最近看过、复杂筛选、工具演示、内容增量导入和运营统计。P1 功能需要单独验收，不以“计划支持”代替已实现。

自建支付、会员账号、课程授权系统、社区和面向访客的 AI 问答暂不列入首版开发；需要时另立范围。

## 5. 四条核心流程

### 5.1 找节目与连续观看

首页选择「百家樂」→选择子栏目或系列→打开视频页→站内观看→继续下一集。直接从搜索进入视频页时，仍能看到主分类和系列入口。浏览器返回恢复此前筛选；离开网站前往 YouTube 使用明确链接。

### 5.2 查事件与资料

首页／搜索→事件或专题→阅读导读→观看关联视频→查后续或来源。视频是具体作品，专题是整理入口，两者互相引用，不把所有正文复制到多个分类地址。

### 5.3 了解课程并咨询

主题分类或课程中心→同一课程详情→阅读目录和条件／试看→选择联系渠道。咨询入口带课程名称，最终发送由观众完成。未确认的商业信息留在编辑待核状态，不以旧资料补齐。

### 5.4 使用软件

「百家樂工具」或百家乐页→工具详情→核对用途、版本、设备要求→在线打开或下载→查教程／反馈。已存在的工具优先接入原入口，是否站内嵌入按实际兼容性确定；不能加载时仍可从详情页进入独立工具。

## 6. 状态与异常

| 场景 | 观众看到的结果 | 可继续的动作 |
| --- | --- | --- |
| 分类暂未有已发布条目 | 简短真实说明；四大主入口仍保留，空子栏目不展示 | 回分类总览、看其他栏目 |
| 筛选后无结果 | 「沒有符合條件的內容」并显示当前条件 | 清除筛选或重新搜索 |
| 搜索未输入 | 输入提示和四大分类入口 | 输入关键词或浏览分类 |
| 搜索无结果 | 「找不到相關內容」和建议修改关键词 | 清除条件，不生成虚构答案 |
| 会员／受限视频 | 明确权限标识、可公开摘要与 YouTube 入口 | 到原站核验自身权限 |
| 嵌入失败 | 说明播放器暂不可用，保留标题和资料 | 重试或前往 YouTube |
| 视频已失效 | 如实标记，已核实才写失效原因 | 看相关可用内容；保留有价值公开资料 |
| 课程价格或联系渠道未确认 | 隐藏未知字段；只展示仍然有效的信息 | 已有有效渠道才显示咨询动作 |
| 工具开发中／停止维护 | 显示真实状态、适用说明与已确认信息 | 阅读教程或返回工具中心，无空操作按钮 |
| 资料／文字稿未完成 | 不显示尚不存在的下载或全文入口 | 看已完成摘要、视频与关联资料 |
| 不存在的地址 | 404 状态与可用导航 | 搜索、回首页或对应分类 |

## 7. 质量与发布条件

手机以常见窄屏开始检查，正文建议18—20px、主要点击区域至少44×44 CSS px，200%缩放仍可阅读。所有按钮与菜单支持键盘、可见焦点和清楚名称；图片提供有意义的替代文本。播放器保持比例，列表仅加载缩略图。性能数据在真实首版产生后记录，不编造测量分数。

首版发布清单以经核验的范围为准：全部条目有归属和有效去向；真实观众路径通过；无关键断链或空操作；课程信息一致；工具状态准确；资料公开范围正确；新旧地址有对照。全量目录完成与全文资料完成分别统计。

## 8. 结果指标

交付硬指标是发布范围内归档完整率、唯一性、关键入口有效性及需求验收结果。上线后观察搜索展示与点击、系列继续观看操作、课程咨询按钮点击、工具启动／下载点击和内容更新耗时。点击不等于观看完成、发出消息或成交。AI描述复测记录平台、日期、问题、事实错误与引用，不承诺固定答案。

## 9. 开发前仍需的输入

公开内容清单及核验状态、当前课程条件与公开联系方式、软件可运行版本与入口、品牌素材及实际旧站域名。缺少某项时先完成模板与状态处理，其发布状态单独记录。数据模型与实现框架由开发架构文档承接；本PRD不将尚未完成的接口、同步和部署写成现有能力。
