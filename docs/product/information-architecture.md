# 凱利策略網站｜信息架构与路由 V1

日期：2026年11月8日｜美国洛杉矶时间
状态：开发规格；路由与页面待实现。关联：[PRD V1](prd-v1.md)。

## 1. 组织原则

四大内容分类表达观众关心的领域。「課程中心」和「百家樂工具」表达明确任务，是独立导航入口。主题、内容形式、系列、权限和地区分别记录。页面可从多个入口进入，作品、课程和工具各自拥有一个权威详情地址。

顶层导航：**首頁｜百家樂｜老虎機｜賭場追查｜博彩雜談｜課程中心｜百家樂工具｜關於凱利｜搜尋**。

网站公开界面默认繁体中文；检索保留简繁别名及原始标题。技术路由使用稳定的 ASCII slug，不随标题微调而更换；内部ID稳定且唯一，用于记录关联，slug变更必须登记重定向。本文中的占位参数是路由模板，不代表内容或产品已经存在。

## 2. 路由清单

| 页面 | 路由 | 面包屑／主导航归属 | 说明 |
| --- | --- | --- | --- |
| 首页 | `/` | 首頁 | 所有入口的总览 |
| 百家樂 | `/baccarat/` | 首頁 › 百家樂 | 主分类ID：baccarat |
| 老虎機 | `/slots/` | 首頁 › 老虎機 | 主分类ID：slots |
| 賭場追查 | `/investigations/` | 首頁 › 賭場追查 | 主分类ID：investigations |
| 博彩雜談 | `/commentary/` | 首頁 › 博彩雜談 | 主分类ID：commentary |
| 子栏目 | `/{category}/{section}/` | 首頁 › 主分类 › 子栏目 | section 必须是该分类的已登记子栏目 |
| 系列 | `/series/{slug}/` | 首頁 › 主分类 › 系列 | 序列内容；跨分类仍为一个系列页 |
| 专题 | `/topics/{slug}/` | 首頁 › 主分类 › 专题 | 非线性集合，可含多种内容形式 |

| 文章／资料 | `/articles/{slug}/` | 首頁 › 主分类 › 文章 | 原文日期、更新日期、作者与关联来源 |
| 事件档案 | `/articles/{slug}/` | 首頁 › 賭場追查 › 事件 | `kind=article, article_type=event`，同文章命名空间，使用事件版式 |

| 工具中心 | `/tools/` | 首頁 › 百家樂工具 | 导航ID：baccarat-tools；也由百家乐页链接 |
| 工具详情 | `/tools/{slug}/` | 首頁 › 百家樂工具 › 工具 | 使用状态、教程与版本信息 |

| 搜索 | `/search/?q={query}&type={type}&category={category}` | 首頁 › 搜尋 | 查询参数可分享和恢复 |

路由参数仅接受登记值，未知分类／子栏目组合返回404。全站选择尾斜杠规范并统一处理；上线旧网址经盘点后建立逐项重定向，不预设未核实域名或旧地址。

### 交叉内容判定

核心任务是追查具体事件、监管或玩家遭遇，主归「賭場追查」；核心任务是解释或观察某种游戏，主归相应游戏。主归属用于统计及面包屑，可用专题和标签关联其他领域。系列顺序、形式、观看权限和课程关系独立，不依赖标题关键词推断。

## 4. 页面内容顺序

### 首页

频道名称与短介绍→四大分类（附真实子栏目）→精选或推荐起点→最新更新→重点专题→课程与工具→关于和联系。课程与工具也始终可从全站导航进入。编辑精选来源必须明确，不将其称为个性化推荐。

### 分类与子栏目页

标题与介绍→子栏目导航→系列／专题入口→内容筛选与列表→相关课程／工具。列表显示标题、封面、类型、时长或日期、受限标识；只展示有依据的字段。数据较多时使用分页或可分享的分页参数，后退恢复页码与筛选。

### 视频页

面包屑→标题与原始发布日期→播放器／权限状态→YouTube入口→本集摘要与章节→系列目录→文字资料、来源和更新→相关内容。桌面系列目录可与播放器并排；手机回到单列。不在页面底部才告知视频受限。

### 专题与事件

专题：标题与问题导读→推荐阅读／观看顺序→影片→文章／图解→来源与后续。事件：标题与最近更新→事件概述→事件时间线→关联报道／视频→来源与更正。没有实际来源的“证据区块”不生成。

### 课程

课程中心：介绍→按主题筛选→课程卡片。详情：名称、简介与状态→适合对象→目录→试看→交付与现行条件→咨询→相关公开内容。课程价格和商业条件读取同一权威记录；卡片不保存独立副本。

### 工具

工具中心：用途介绍→按真实状态分组／筛选→工具卡片。详情：名称与状态→功能说明与截图→版本及设备要求→在线／下载入口→教程→更新记录与反馈。未核验入口不显示可执行按钮。下载文件和在线页面可以在其他已核实位置，不为导航强制搬迁或重写工具。

## 5. 桌面与手机导航

桌面优先显示六个内容／功能入口；空间不足时收起辅助项，不压缩成难读小字。搜索、关于与首页始终可访问。手机使用带文字名称的菜单按钮，展开后列出四大分类、课程、工具、关于和搜索；关闭后恢复焦点。

首页手机端四类入口可两列展示；课程与工具用独立明显入口，不藏在分类筛选里。分类标签在窄屏可换行，不靠用户发现横向拖动才能访问。浏览器返回保留选择的条件与列表位置。

## 6. 关系、规范地址与去重

| 对象 | 唯一主记录 | 允许出现的入口 | 权威详情 |
| --- | --- | --- | --- |
| 视频 | content ID 与YouTube ID唯一 | 分类、系列、专题、搜索、相关内容 | `/videos/{slug}/` |
| 课程 | course ID唯一 | 对应主题、课程中心、视频推荐 | `/courses/{slug}/` |
| 工具 | tool ID唯一 | 工具中心、百家乐、教程、搜索 | `/tools/{slug}/` |
| 文章 | article ID唯一 | 分类、专题、事件、视频资料区 | `/articles/{slug}/` |

分类目录不复制详情正文。搜索结果、标签筛选和分页URL不成为同一内容的另一详情。面包屑依据主归属生成；来源入口可以另外提供“返回先前列表”，不改变页面规范地址。

## 7. 状态与搜索边界

记录的公开状态、页面发布状态、视频观看权限、软件可用状态分别处理。允许公开的会员视频介绍可被搜索，会员视频正文／私享链接不会随目录公开。内部原件和未审核草稿不进入静态搜索文件、页面数据和站点地图。

空结果提供清除条件；缺少可选资料隐藏对应区块；不可播放提供原站入口；无当前有效联系信息不显示虚假“立即咨询”动作；已下线工具保留有价值的说明与状态。404页面提供四类、课程、工具和搜索的有效去向。

## 8. 交付前检查

1. 六个主入口均有实际页面与正确显示名。
2. 每个发布详情只有一个稳定地址，课程和工具交叉入口一致。
3. 四类找内容、系列连续观看、课程咨询、工具使用路径符合PRD。
4. 初始HTML有真实标题、简介与可访问内部链接。
5. 手机菜单、返回、筛选、空结果和受限状态可操作。
6. 系列、专题与事件的关系来自数据，不因页面布局丢失内容。
7. 未发布或内部内容没有进入页面、搜索、下载或站点地图。
