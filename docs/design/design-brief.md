# 网站设计任务书

版本：V1｜2026年11月8日｜美国洛杉矶时间

## 设计目标

让观众清楚找到节目、继续观看、读补充资料、了解课程和使用工具。保留观众熟悉的视频操作，同时增加YouTube缺少的分类与资料层次。面向中文观众，重点验证40岁以上读者的字号、点击目标和理解成本。

## 参考关系

| 参考 | 借鉴 | 本站的具体应用 |
| --- | --- | --- |
| [TED](https://www.ted.com/) | 视频、文字与专题相互延伸 | 详情页可观看也可阅读，相关资料有组织 |
| [ARTE](https://www.arte.tv/en/) | 类别、节目与系列并存 | 四大分类清楚，系列推荐与最新更新各自成组 |
| [YouTube](https://www.youtube.com/) | 缩略图、播放与连续观看习惯 | 16:9卡片，明确播放入口，关联系列目录 |

已完成官方页面结构与说明研究；下一阶段仍需逐屏检查具体参考页面及手机体验。不得把文字检索说成已经完成视觉评审。

## 两个可比较的首页稿

- A：优先分类与找片。开场短介绍、四类目录、精选、最新、系列、课程与工具。
- B：优先专题与阅读。开场仍露出四类目录，重点专题更靠前，视频与文章并列展示。

两稿使用同一批真实且可公开的内容。不能用虚构标题、工具截图或课程价格比较效果。选定一个底稿继续，不并行维护两站。

## 视觉约束

- 公开界面使用繁体中文；资料原标题与作者原话保留，不机械改变内容意思。
- 浅色阅读背景、深色正文为建议起点；品牌色须依据已有标识确认。
- 桌面正文建议18—20px，行高1.6—1.8；手机正文不因排版压成小字。
- 正文列宽控制在舒适阅读范围，视频与目录可以使用更宽布局。
- 不自动播放带声音的视频；不靠自动轮播承载关键入口。
- 手机按钮目标建议至少44px；键盘可达、有可见焦点，基础文字对比达到WCAG AA。
- 列表显示内容类型、时长或日期、受限状态；不能仅用颜色传达权限或版本。

## 必须画出的页面与状态

首页；百家乐分类；老虎机分类；系列页；视频页；资料页；课程中心及详情；百家乐工具中心及详情；搜索结果；404。

同时画出：无搜索结果、播放器无法嵌入、会员观看入口、无可用工具版本、课程价格待核、尚无该类内容。空状态给真实下一步，不放无效按钮。

## 主要用户任务

1. 从首页找到百家乐异常系列并进入某集。
2. 找到老虎机现场视频后继续观看同类内容。
3. 查赌场事件并找到后续。
4. 找课程、看清形式与条件、选择咨询方式。
5. 找工具、辨认可用状态、开始使用或查看教程。
6. 从视频进入相关文字资料，再回到同一系列。

从首页至目标详情不超过三次主要导航点击。手机返回后保留原筛选和合理滚动位置。

## 页面实现前交付

可检查的两套首页稿；至少一条完整找片路径、一条课程路径、一条工具路径；手机布局；组件和字号／间距规范；采用与放弃参考元素的理由。未拿到真实资产的模块明确列缺口，不伪造“在线可用”。
