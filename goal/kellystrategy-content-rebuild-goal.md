# Goal：凱利策略內容官網與 YouTube 頻道重整

**版本：** 0.1  
**狀態：** 進行中；分類資料仍在首輪對照  
**資料基線：** 2026-11-09 YouTube Studio 匯出與合併影片清單

## 北極星

讓新觀眾與老觀眾都能快速看懂凱利策略在研究什麼、有哪些代表內容、如何沿著主題深入；以網站的分類、文章、圖片和互動補足 YouTube 的展示限制，並自然導回 YouTube。網站同時要成為搜尋引擎與 AI 可讀、可引用的頻道說明與內容索引。

網站不是把影片縮圖堆在一起的第二個 YouTube。每個影片都要被放進可理解的內容脈絡：

**大模組 → 系列 → 播放列表／主題 → 影片**

## 目標使用者與任務

1. **新觀眾**：幾分鐘內理解頻道定位，從代表作進入感興趣的大模組。
2. **老觀眾**：不必在大量影片中無限下滑，能按系列及播放列表找到特定內容。
3. **課程意向觀眾**：先看課程範圍，再以已核實的郵件、微信或 WhatsApp 入口聯絡。
4. **搜尋引擎與 AI**：能辨識創作者、頻道定位、主題分類、系列、影片、文章與工具之間的關係，並看到清楚的來源和更新資訊。
5. **頻道營運者**：先在官網確認影片歸屬，再把已核准的系列與播放列表結構同步回 YouTube Studio。

## 固定內容分類

### 主要模組

- 百家樂
- 老虎機
- 賭場追查
- 博彩雜談
- 課程中心
- 百家樂工具
- 關於凱利

「頻道入口／精選」可作跨模組導流集合，不取代上述主分類。

### 模組內的四級目錄

1. **大模組**：上列內容入口。
2. **系列**：具有穩定主題和清晰定位的內容群。例如「老虎機拆解｜機制、內幕與策略」。
3. **播放列表／主題**：系列中的具體 YouTube 播放列表。保留原始播放列表 ID、名稱和連結；重命名建議另列，不覆寫來源。
4. **影片**：真實影片 ID、標題、URL、縮圖、類型、發布日期及可取得的觀看數快照。

課程中心使用同一層級原則：課程中心 → 課程系列 → 課程播放列表／章節 → 單課影片。

同一影片可以有多個有效歸屬，但每個歸屬都必須有明確來源；不得因重複出現而複製或改寫影片的來源資料。

## 產品與編輯原則

- 模組首頁以代表影片和清楚的系列橫欄為主；每欄展示少量影片／播放列表入口，完整列表另開頁。
- 系列頁按播放列表／主題分組，不把數十至數百支影片全部展成單一長列表。
- 播放列表頁提供影片網格、標題、縮圖、觀看數快照、搜尋／分頁，以及 YouTube 原片入口。
- 首屏輪播內容由頻道實際播放數據和創作者代表性判斷共同確認；不得把「觀看數最高」自動等同於「最能代表頻道」。
- 文章、圖像、課程視覺和互動工具補足影片之外的說明空間；不得打斷影片分類主線。
- 觀看數是匯出時的快照，頁面要標明可能滯後；最新播放數以 YouTube 為準。
- 不使用未經核實的課程價格、承諾、工具可用狀態、聯絡資料或盈利說法。

## 資料來源與隱私邊界

### 來源優先序

1. YouTube Studio 影片清單：影片 ID、可見狀態、影片形式、發布時間、觀看數。
2. Studio 播放列表資料：播放列表 ID、名稱、可見狀態、Studio 數量。
3. 播放列表成員資料：影片與播放列表的實際關係。
4. 公開頻道頁抓取資料：僅補充 Studio 缺少的公開資訊，不能推翻 Studio 權限狀態。
5. Google Drive、GitHub 等自有資料：補充文章、工具和品牌素材；每個採用項目保留來源與審核狀態。

### 網站資料發布規則

- 公開網站目錄只收 Studio 明確標記為公開的影片。
- 會員、私人、不公開，以及 Studio 未匹配的影片，不得混入公開影片目錄或公開搜尋索引。
- 會員內容要進網站前，先確定要使用會員資格提示、YouTube 會員入口或其他經 Miles 核准的存取方式。
- 原始匯出、私人 Drive 路徑、憑證和內部聯絡資訊不進公開網站倉庫。
- 未確認歸屬要明確標示「待核」，不得由自動規則假裝成定稿。

## 成功指標與驗收門檻

### 目錄完整度

- 來源影片總數、Studio 匹配數、公開／會員／不公開／私人／未匹配數可以互相核對。
- 每支已核准公開影片都有正確的影片 ID、標題和原片連結。
- 每支已核准公開影片都有至少一條已審核的四級歸屬；未確認影片留在明確的待核佇列。
- 每個網站公開播放列表都有真實 YouTube playlist ID；沒有空殼假列表。
- 任何公開頁面或搜尋索引都不含非公開影片 ID。
- 自動分類只是建議；所有公開模組、系列及播放列表關係須經人工抽查批准。

### 觀眾任務

- 新觀眾從首頁能進入七個主要模組，並找到模組代表內容。
- 老觀眾最多三次分類選擇可到達目標播放列表；列表頁不以無限長頁代替分層。
- 影片卡片能前往網站影片頁或 YouTube 原片，YouTube 路徑不可失效。
- 課程諮詢入口只呈現已核實的聯絡方式。

### AI／搜尋理解

- 首頁、關於頁和各模組頁使用一致且清楚的頻道定位、繁簡體別名和主題詞。
- 每個內容頁有唯一標題、摘要、規範 URL、麵包屑與可解析的內容關係。
- 搜尋機器人設定在試作、驗收和正式公開階段分開管理；不可把 `noindex` 原型當成正式 SEO 已完成。

## 階段與放行條件

### G0｜資料盤點與差異核對（目前）

- 導入 Studio 影片、播放列表和成員資料。
- 建立含四級欄位、可逐行審核的清單。
- 調和 Studio 匹配缺口、觀看數差異、會員與非公開狀態。
- **放行條件：** 有具體差異報表；待核項可追溯，沒有把未知當作公開或已分類。

### G1｜四級分類定稿

- 先完成百家樂、老虎機、賭場追查，再處理博彩雜談與課程中心。
- 為每支公開影片確定主模組、系列、播放列表；多重歸屬以額外放置記錄。
- 產出需要新建、合併、拆分或改名的 YouTube 播放列表建議，等 Miles 審核後才動 Studio。
- **放行條件：** 影片、播放列表和網站模組三向對得上；創作者核准的項目標記為 approved。

### G2｜網站目錄接入

- 從已批准的目錄資料生成模組、系列、播放列表和影片頁。
- 加上代表作、圖片／文章延伸、工具與課程入口。
- **放行條件：** 內容、隱私、導覽、手機和連結 Harness 全部通過。

### G3｜YouTube Studio 整理提案與同步

- 以 G1 批准資料為唯一操作清單，逐項整理播放列表、封面、名稱、說明和首頁欄目。
- 先提供變更前後對照；得到 Miles 明確批准後才在 Studio 執行。
- **放行條件：** Studio 與官網四級目錄一致，並記錄變更和回退方式。

### G4｜正式搜尋與持續維護

- 核准公開後再更新索引政策、結構化資料、站點地圖和頻道關聯。
- 設定資料更新流程，定期核對新影片、播放數、播放列表和工具狀態。
- **放行條件：** 搜尋可抓取、來源可核驗、更新責任與頻率已定。

## 明確不做

- 不把 1,222 個來源 ID 全部當成公開影片。
- 不在創作者核准前修改、刪除、移動或重新命名 Studio 影片與播放列表。
- 不以自動按關鍵字分類取代人工判斷。
- 不把課程頁做成沒有可靠內容和聯絡資料的購買承諾頁。
- 不為了追求內容量而把大量無關內容塞進同一模組。

## 當前基線（2026-11-09）

來源合併清單有 1,222 個唯一影片 ID；其中 1,002 個能與 Studio 影片列匹配。網站公開審核目錄包含 442 支 Studio 明確標記公開的影片；其中 298 支連到不含會員標示的公開播放列表，144 支尚待播放列表匹配。Studio 匯出中有 56 個標記公開的播放列表；其中 13 個名稱標示會員專享的列表不納入公開審核分支，另有 4 個已納入的列表自動分類仍待人工核准。這些數字是工作基線，不代表頻道最終公開影片總量；與 Miles 所說的 700 多支差異必須在 G0 核清。
